# chirashi-master

This is the main repository for Chirashi Master, a system for automated publishing to CAFE24.

## Features

- Automated publishing to CAFE24
- Admin-only board detection
- Access control checks
- Publishing block conditions

## Getting Started

1. Clone the repository
2. Install dependencies
3. Configure environment variables
4. Run the application

## Deployment

This project uses Cloudflare Workers for deployment.
