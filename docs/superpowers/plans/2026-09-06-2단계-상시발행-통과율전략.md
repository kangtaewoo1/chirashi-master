## Task 2A: 24시간 상시발행 루프 (`publish_loop`)  ★핵심

**Files:**

- Modify: config 기본값에 `publish_loop_enabled`, `publish_interval_sec` 추가.

**Interfaces:**
- Consumes: `load_sites()`, `is_publishable`, `under_daily_limit`, `under_min_interval`, `load_keywords`, `enqueue_generated`, `load_config`.
- Produces: `publish_loop()` — 주기적으로 발행가능 사이트 중 하루한도·간격 통과한 곳에 키워드 풀 기반 글을 큐잉하는 상시 루프.

**설계:**
- 주기: 기본 300초(5분)마다 1회 점검. (워커가 실제 발행하므로 루프는 큐 보충 역할)
- 매 점검: 발행가능 사이트 순회 → `under_daily_limit && under_min_interval` 통과 사이트만 → 큐에 이미 대기중이 아니면 → 키워드 1건 뽑아 `enqueue_generated`로 큐잉.
- 키워드 풀이 비면 아무것도 안 함(로그 1회).
- 큐가 이미 꽉 차 있으면(예: qsize > 발행가능수*2) 스킵 — 과잉 큐잉 방지.
- 안전장치: 실제 발행 직전 워커가 다시 하루한도·간격·publishable 확인하므로 이중 안전.

- [ ] **Step 1: config에 상시발행 설정 추가**


- [ ] **Step 2: publish_loop 함수 추가**

`discover_loop` 함수 정의 바로 다음(4161줄 이후, discover_loop의 `time.sleep(60)` 끝난 뒤)에 추가:

```python
def publish_loop():
    """24시간 상시발행: 발행가능 사이트 중 하루한도·간격 통과한 곳에 키워드 풀 기반 글을 큐잉한다.
       실제 발행은 worker_loop이 하며, 발행 직전 한도·간격·publishable을 다시 확인한다(이중 안전)."""
    while True:
        try:
            cfg=load_config()
            if not cfg.get('publish_loop_enabled'):
                time.sleep(int(cfg.get('publish_interval_sec',300) or 300)); continue
            sites=[s for s in load_sites() if is_publishable(s)]
            if not sites:
                time.sleep(int(cfg.get('publish_interval_sec',300) or 300)); continue
            # 큐가 이미 충분히 차 있으면 과잉 큐잉 방지
            if post_queue.qsize() >= max(2,len(sites)):
                time.sleep(int(cfg.get('publish_interval_sec',300) or 300)); continue
            pool=load_keywords()
            if not pool:
                add_log('[상시발행] 키워드 풀이 비어 있어 대기 — 키워드 탭에서 추가하세요')
                time.sleep(int(cfg.get('publish_interval_sec',300) or 300)); continue
            queued=0
            for s in sites:
                if not under_daily_limit(s,cfg): continue
                ok,_=under_min_interval(s)
                if not ok: continue
                kwrow=random.choice(pool)
                # 키워드 행 형태: [k1,k2,k3] 또는 dict. enqueue_generated는 dict 기대.
                if isinstance(kwrow,dict):
                    kw={'지역':kwrow.get('지역',''),'서비스':kwrow.get('서비스',''),'브랜드':cfg.get('brand','')}
                elif isinstance(kwrow,(list,tuple)) and kwrow:
                    kw={'지역':str(kwrow[0]),'서비스':str(kwrow[1]) if len(kwrow)>1 else '','브랜드':cfg.get('brand','')}
                else:
                    kw={'지역':str(kwrow),'서비스':'','브랜드':cfg.get('brand','')}
                try:
                    n=enqueue_generated([s],kw,cfg,{'region':kw['지역'],'service':kw['서비스']})[0]
                    queued+=n
                except Exception as e:
                    add_log(f'[상시발행 오류] {str(e)[:80]}')
                if not wk_active: start_workers(cfg.get('workers',2))
            if queued: add_log(f'[상시발행] {queued}건 큐 등록 (발행가능 {len(sites)}곳 중 한도·간격 통과분)')
        except Exception as e:
            add_log(f'[상시발행 루프 오류] {str(e)[:100]}')
        try: time.sleep(int(load_config().get('publish_interval_sec',300) or 300))
        except Exception: time.sleep(300)
```
